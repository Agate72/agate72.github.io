01 / PROJECTMINECRAFT JAVA EDITION

EarthSimulator.

デモ版 · 1.0-SNAPSHOT

実際の地形や街を、Minecraftの中へ。
標高、土地被覆、建物、道路などのデータを組み合わせ、探索できる地球の世界をつくります。

Real terrain. Real places. A world you can build on.
EarthSimulator brings geographic data into Minecraft.

ここで紹介する仕様・データ構成は、現在配布中のデモ版のものです。正式版は一部を修正し、デモ版とは別の版として公開する予定です。

The specifications and data sources shown here apply to the current demo. The full version will include revisions and is planned as a separate release.
