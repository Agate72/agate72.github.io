01 / PROJECTMINECRAFT JAVA EDITION

EarthSimulator.

デモ版 · 1.0-SNAPSHOT

実際の地形や街を、Minecraftの中へ。
EarthSimulatorは、地理データをもとに探索できる世界をつくるMinecraft Java Edition用MODです。

Bring real terrain and places into Minecraft.
EarthSimulator is a mod for Minecraft Java Edition that turns geographic data into explorable worlds.

現在はデモ版を配布しています。正式版は一部を修正し、デモ版とは別の版として公開する予定です。

A demo is currently available. The full version will include revisions and is planned as a separate release.

02 / GET STARTED

デモ版を試す。

Minecraft Java Edition 1.21.1のFabric環境で利用できます。
Fabric APIとFabric Language Kotlinを用意し、デモ版のJARと一緒に mods フォルダへ配置してください。

導入前にワールドと設定をバックアップし、普段のプレイ環境とは別の環境でお試しください。

Place the demo JAR, Fabric API, and Fabric Language Kotlin in the mods folder. Back up your worlds and settings, and try the demo in a separate game instance.

03 / INFORMATION

ご利用にあたって。

生成された地形・街・天候は、現実の状況と異なる場合があります。外部データの提供状況や仕様変更により、一部の機能を利用できなくなる場合があります。

ライセンスの公開状況

現在配布中のデモ版のライセンス表記は「All-Rights-Reserved」です。ソースコードとOSSライセンスは公開準備中です。

Generated terrain, places, and weather may differ from real-world conditions. Some features may become unavailable due to changes in external data services or their availability.

License status

The current demo is marked “All-Rights-Reserved.” Publication of the source code and an open-source license is in preparation.
